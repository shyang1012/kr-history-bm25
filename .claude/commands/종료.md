# `/종료` — 세션 마무리 (beads 동기화 + 커밋)

세션 종료 전 local-first 체크리스트를 수행하라.

## STEP 1 — 세션 요약 (PM 확인)

이번 세션의 **완료된 작업 / 결정사항 / 발생한 이슈 / 다음 할 일**을 추출해 보여주고 승인받는다.

```
📋 세션 요약
### 완료된 작업
- ...
### 결정사항 (있으면)
- ...
### 발생한 이슈 (있으면)
- ...
### 다음 할 일
- ...
이대로 저장할까요?
```

## STEP 2 — beads 동기화 + 세션 맥락 기록

(bd 미초기화 시 건너뜀)

```bash
bd close <id>                                      # 완료된 작업 이슈 닫기
bd create "<제목>" --type task                     # 새 다음 할 일 등재
bd note <id> "<진행 메모>"                          # 진행 중 핸드오프 로그
bd remember "<완료 / 결정 / 다음 — 한두 줄>" --key session-YYYY-MM-DD   # 세션 맥락
```
- 지속 정책·결정은 `--type decision` (유효한 동안 OPEN) 또는 `bd remember --key <주제>`.
- 세션 맥락은 `session-<날짜>` 키로 1건. `/시작`은 최근 3개만 펼치므로, 누적 시 오래된 것은 `bd forget session-<옛날>`로 정리(최근 3회 유지).

## STEP 3 — 품질 게이트 (코드 변경 시)

```bash
npm test                    # vitest 통과 확인
npm run typecheck           # (선택) 타입 확인
```
- 실패 잔존 시 요약에 명시 + 다음 할 일로 등재. 증거 없이 완료 주장 금지.

## STEP 4 — 로컬 커밋 + 옵션 push

```bash
git status --short
git add -A        # .dev.vars·*.key·*.env·source/ 제외 확인
git commit -m "<type>(<scope>): <요약>"   # Conventional Commits
```
- 백업 원하면(또는 PM 요청): `git push` (현재 브랜치만).

## CRITICAL

- 커밋/푸시는 **PM 요청 시에만**. `.dev.vars`(CF 시크릿) 절대 커밋 금지.
- 명시 요청 없이 force-push / 브랜치 rewrite / `bd dolt push` 금지.
- 무관한 로컬 변경 보존. 동봉본 재생성이 필요하면 `npm run build:corpus`.

## 완료 메시지

