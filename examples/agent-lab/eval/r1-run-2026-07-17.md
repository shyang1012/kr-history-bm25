## 실행 2 — agent 스모크 (dev, `--before`)

`AGENT_LAB_MCP=dev npm run agent -w @kr-history/agent-lab -- "낙랑은 어디에 있었나" --before`

```

(빈 문자열)

=== grounding ===

=== outcomes ===
  (없음)

=== before ===
```

- **after (도구 有)**: `finalText` **빈 문자열**, `outcomes` 없음 — 페르소나로는 도구 자율 호출 안 함.
  (`gemma4:e2b`는 답을 OpenAI `reasoning` 필드에 담고 `content`를 비워 반환 → `OllamaModelCaller`가
  `reasoning`을 discard → 도구도 안 부르면 답이 사라짐.)
- **before (도구 無)**: few-shot의 호출 구문을 **텍스트로 흉내만** 냄(실제 호출 아님).

## 실행 3 — Ollama 직접 probe (강한 명령형 프롬프트)

`gemma4:e2b`가 tool_calls를 애초에 방출하는지 분리 검증. 요청은 `call_mcp` 스키마 1개 + 명령형 지시.

**요청**(`probe.json`):
```json
{"model":"gemma4:e2b","messages":[{"role":"user","content":"樂浪(낙랑)에 대해 사료를 찾아줘. 반드시 call_mcp 도구를 써서 search_han으로 樂浪을 검색해."}],"tools":[{"type":"function","function":{"name":"call_mcp","description":"MCP 도구를 호출한다","parameters":{"type":"object","properties":{"server":{"type":"string"},"tool":{"type":"string"},"args":{"type":"object"}},"required":["server","tool","args"]}}}],"tool_choice":"auto"}
```

**응답**(핵심 발췌):
```json
{
  "choices": [{
    "message": {
      "role": "assistant",
      "content": "",
      "reasoning": "...(생략) I have access to call_mcp(server: str, tool: str, args: dict). ... server: I need to select a plausible server if one isn't provided ... tool: search_han ... args: 樂浪 ...",
      "tool_calls": [{
        "id": "call_495x978w",
        "type": "function",
        "function": {
          "name": "call_mcp",
          "arguments": "{\"args\":{\"query\":\"樂浪\"},\"server\":\"search_han\",\"tool\":\"search_han\"}"
        }
      }]
    },
    "finish_reason": "tool_calls"
  }],
  "usage": {"prompt_tokens":120,"completion_tokens":346,"total_tokens":466}
}
```

- ✅ **tool_calls 방출 성공** — 강한 명령형엔 `call_mcp`를 부른다(능력 있음).
- ❌ **중첩 스키마 오구성**:
  - `server: "search_han"` — 도구명을 `server` 슬롯에 넣음. **`"krh"`가 아니며 `enum:['krh']`를 무시**.
  - `args: {"query": "樂浪"}` — arg 키가 `query`. **`search_han`의 실제 필수 인자는 `term`**
    (`src/mcp/tools.ts`: `term: z.string().min(1)`) → ajv `invalid-args`.
  - `tool: "search_han"` — 유일하게 정확.
- 우리 하네스에 실제로 흘렀다면 결과: Q-01 allow-list(`server≠'krh'`) → `invalid-args` → `bridge.callTool` 미호출.

## 분석 — R1 판정: 부분 반증

| 항목 | 결과 |
|------|------|
| 하네스(8도구·브릿지·멀티라운드·계측·접지) | ✅ 완전 작동 (end-to-end) |
| 도구호출 **능력** | ⚠️ 있음 (강한 명령형 프롬프트 한정) |
| **자율** 호출 (평이 질문 + trust-principle 페르소나) | ❌ 안 함 |
| 2단 중첩 `(server, tool, args)` 정확 구성 | ❌ `server`에 도구명·arg 키 오류 |

**2B 온디바이스 모델은 범용 메타도구의 2단 중첩을 안정적으로 자율 구성하지 못한다** — R1이 예측한
정확한 실패모드. 하네스 결함이 아니라 모델 능력의 경계.

### 다음 실험 후보
- (a) **프롬프트 하드닝** — `server='krh'` 고정 강조, 도구별 정확 arg 키(`term`/`query`) few-shot, 명령형 지시.
- (b) **`reasoning` fallback 파싱** — `content` 비고 `reasoning`만 있을 때 대비.
- (c) **상위/4B 모델 대조** — 중첩 자율구성 능력의 파라미터 임계 관찰.
- (d) **도구별 직접 노출**(재래핑)로 중첩 1단 완화 — 단 "범용 call_mcp 하나로" 가설과 트레이드오프.

## 재현 명령

```bash
# 0) 모델·빌드
ollama pull gemma4:e2b
npm run build                      # dist/mcp/server.js (dev 프로파일용)

# 1) e2e (하네스 계약, 실 Ollama+MCP)
AGENT_LAB_E2E=1 AGENT_LAB_MCP=dev npm run test -w @kr-history/agent-lab -- e2e

# 2) agent 스모크 (before/after)
AGENT_LAB_MCP=dev npm run agent -w @kr-history/agent-lab -- "낙랑은 어디에 있었나" --before

# 3) Ollama 직접 probe (tool_calls 방출 확인)
curl -s http://localhost:11434/v1/chat/completions -H "Content-Type: application/json" -d @probe.json

# (product 모드: AGENT_LAB_MCP=product — 빌드 불필요, npx 배포판)
```

> ⚠️ LLM 출력은 비결정적 — 위 로그는 2026-07-17 1회 관측이다. 표기·arg 키 오류의 구체 형태는
> 실행마다 다를 수 있으나, "2단 중첩 자율구성 불안정"이라는 질적 결론은 반복 관측 대상이다.
