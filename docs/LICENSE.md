# docs/ 문서 라이선스 — CC BY 4.0

이 저장소의 **`docs/` 하위 문서**(`docs/**/*.md`)는 다음 라이선스로 공개한다.

> **Creative Commons Attribution 4.0 International (CC BY 4.0)**
> © 2026 shyang
> 요약(deed): <https://creativecommons.org/licenses/by/4.0/deed.ko>
> 전문(legalcode): <https://creativecommons.org/licenses/by/4.0/legalcode>

**저작자 표시**를 유지하면 복제·배포·전시·2차적 저작물 작성·상업적 이용이 자유롭다.

## 저작자 표시 방법

문서를 인용·재사용할 때 아래 형식을 권장한다.

```
양승현(shyang), 「{문서 제목}」, kr-history-bm25, {연도}.
https://github.com/shyang1012/kr-history-bm25 — CC BY 4.0
```

## 🔴 이 라이선스가 적용되지 않는 것

| 대상 | 라이선스 |
|------|----------|
| 소스 코드(`src/`·`tests/`·`scripts/`)와 npm 패키지 `kr-history-bm25` | **MIT** — 루트 [`LICENSE`](../LICENSE) |
| `README.md`(패키지 동봉 사용자 문서) | **MIT** — 패키지와 함께 배포된다 |
| 사료 원자료(`source/`)와 이를 적재한 동봉 코퍼스(`data/`)의 **원문 텍스트** | **국사편찬위원회 한국사 데이터베이스** — 권리는 해당 기관에 있으며 저작자가 라이선스할 수 있는 대상이 아니다 |

즉 CC BY 4.0의 대상은 **저작자가 직접 작성한 문서(설계·평가·방법론 기록)의 서술**이다.
방법론·아이디어 자체는 저작권의 보호 대상이 아니며, 이 문서들의 공개는 그 표현에 대한 저작자
표시와 공개 시점 기록을 목적으로 한다.
